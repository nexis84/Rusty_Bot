The full Little Things list plus the Audio changes from the Fractured Skies notes.

At a glance

Small changes, grouped by the part of the client they touch.

24 changes

Quality-of-life fixes across seven Little Things categories plus two Audio changes.

8 areas

Pirate Insurgency, character/corp, fleet, overview, fitting/industry, skills, interface and audio.

Mostly automatic

Many changes apply without any setup: broadcast options, overview groups, fitting imports and audio cleanup.

A few new settings

Watchlist auto-open, overview header sorting and bookmark expiry are optional toggles you can control.

Pirate Insurgency

FOB asset delivery now defaults to Zarzakh.

FOB assets go to Zarzakh

Pirate Insurgency FOB assets are now sent to Zarzakh by default, rather than the closest lowsec system. If the pirate faction wins the Insurgency, the tax is lowered to 0.5% instead of 15%. Assets can be delivered manually immediately and will auto-redeem after one day on victory.

Character & Corporation

Corporation management moves into a new Memberships tab.

Memberships tab

Resign as CEO and Quit Corp are removed from the right-click menu. A new Memberships tab under Character Sheet > Character shows corporation, alliance and faction memberships, and lets you remove roles, block role assignment, resign as CEO and quit your corporation.

Fleet & Broadcasts

More feedback for jumps, and more control over the watchlist.

Cyno jump/bridge feedback

The HUD now shows temporary text when jumping or bridging to a cyno: “Preparing jump/bridge to {system}” before the command is issued, then “Jumping/bridging to {system}” while the jump or bridge is in progress.

Heal Target broadcast

The broadcast radial menu now includes a Heal Target option.

Broadcast history radial menu

The radial menu now opens for entries in the broadcast history. It shows the broadcaster, target, item or location depending on the broadcast type. If the target is no longer accessible, the menu is empty.

Watchlist auto-open setting

The More menu in the Fleet Watchlist now has an option to stop the watchlist opening automatically when you join a fleet. The main Fleet window can still open it at any time.

Multi-select watchlist colors

Select several watchlist entries with Ctrl+A or Shift, then change one selected entry's color to change them all. Changing an unselected entry still only affects that entry.

Overview

New groups and a header-sorting toggle.

FW Rally Point group

Rally Point beacons in FW Battlefields and Insurgency Ice Heists moved out of Large Collidable Object into a new FW Rally Point group. You can add them to custom overviews without adding every large collidable object.

Item Traders group

Item Traders, including campaign item traders, now have their own group. Add them to custom overviews without other objects. The item trader window also updates after inventory changes.

Overview header sorting toggle

Right-clicking overview headers shows “Header sorting enabled”, checked by default. Uncheck it to stop header clicks changing the sort column or order. A message and header icon show the state. The setting applies to all overviews, is saved per character and persists between sessions on the same computer.

Fitting, Industry & Inventory

Faster imports, item-ID search and wider industry previews.

Duplicate fitting names

Importing an XML fitting with the same name as an existing fitting now appends “_<number>” to the new fitting name.

Clipboard fittings to Multibuy

Fittings in the clipboard can now be imported into Multibuy. Text in “[shipType, shipName]” is handled when importing a shopping list, so the ship name can be included.

Item Filter text import

The Item Filter window has a text import button. It imports items from the clipboard without changing the Match checkboxes or the filter name, and existing conditions stay unchanged. You can also drop a fit into the window to add it.

Search by item ID

You can now search by exact item ID in item containers, asset search and Industry. Asset search also has a new advanced search option for item IDs.

Wider Industry preview fields

Preview fields in the Industry window are wider so their full values are visible. The preview appears when you double-click in the section.

Skills

More useful skill-plan totals and a cleaner catalogue tooltip.

Skill plan SP totals

Skill Plans now show total SP information. When viewing a skill plan, the text under the progress circle shows the SP you have trained and the total training time.

Skill Catalogue info icon

In the Skill Catalogue, the info icon moved from the skill description tooltip to the entry itself, where it appears on mouseover. Skill Plan entries still show info icons in their tooltips.

Interface

Chat links, bookmark expiry, tag shortcuts and fewer annoying pop-ups.

Drop links into chat

Drop any link onto a chat tab to add it to that chat's input field. Nothing is sent automatically. The link is appended to the end of any existing text, and the tab blinks briefly.

Edit bookmark expiry

Bookmark expiry times can now be edited. The old Cancel expiry checkbox is replaced by edit expiry, which lets you add an expiry time. The options only apply when checked. Moving a bookmark between folders preselects the folder's default expiry, but only applies it if edit expiry is checked.

Reset tag sequences shortcut

A new shortcut, Reset tag sequences, resets all tag sequences at once.

“Do not show again” on site pop-ups

Site pop-ups that only have a Close button now include a Do not show again option. It only suppresses the pop-up when you use the Close button, not the X in the upper-right. Messages with warp or set-destination buttons are not affected.

New help pointers

New help pointers are added for Brand management, Wallet - PLEX, Wallet - Evermarks and Corporation Ads.

Audio

Tutorial music and a fix for stuck jump/dock sounds.

Tutorial music re-synced

The tutorial music has been updated and re-synchronized, and now adapts to recent narrative changes. The timing of some NPC conversations was adjusted to improve the dramatic flow.

Jump and dock audio cleanup

Safeguards were added to jumping and docking to prevent sounds repeating indefinitely. When you jump through a stargate or dock in a hangar, the audio system now cleans up sounds that may have gotten stuck on your camera.

FAQ

What are the Little Things?

Small quality-of-life changes that improve everyday EVE Online use. This page covers the Little Things section plus the Audio changes from the same expansion.

How many changes are covered?

24 changes across eight areas: Pirate Insurgency, character/corporation, fleet and broadcasts, overview, fitting/industry/inventory, skills, interface and audio.

Is this a new system?

No. These are fixes and improvements to existing systems rather than a new feature set.

What changed for fleet watchlists?

You can stop the watchlist opening automatically when joining a fleet, and you can change the color of multiple selected entries at once.

What changed for broadcasts?

The radial menu has a new Heal Target option, and it now opens for broadcast history entries with context for the broadcast type.

What changed for the overview?

FW Rally Points and Item Traders have their own groups, and overview header sorting can be disabled with a new right-click toggle.

What changed for fittings and industry?

Duplicate XML fitting names get a number suffix, clipboard fittings import into Multibuy, Item Filter supports text import, item-ID search works in more places, and Industry preview fields are wider.

What changed in audio?

Tutorial music was updated and re-synced, and new safeguards clean up sounds that could repeat indefinitely when jumping or docking.
