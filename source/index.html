How it works

1

Create a room

Enter your Twitch channel, Kick channel, entry command, mode and prize. You get a room code and host key.

2

Add the overlay

Copy the OBS overlay URL from the control panel. Add it as a Browser Source at 320×720 with transparency.

3

Open the draw

Click Open Draw. Viewers type !join (or your custom command) in Twitch or Kick chat. Optionally start the giveaway timer to show a countdown on the overlay.

4

Pick a winner

Click Start Draw. The winner confirms in chat within 90 seconds and gets an ESI character card.

OBS setup

In your Rustybot Source control panel, copy the overlay URL. It looks like this:

https://source.rustybot.co.uk/overlay/YOUR-ROOM-CODE
  • Add a Browser source in OBS.
  • Paste your room's overlay URL and set width 320, height 720.
  • Tick Allow Transparency so the overlay sits over your scene.
  • Optional: tick Control audio via OBS for winner and countdown sounds.

No room yet? Create one, then copy the exact URL from the control panel. The button above copies the demo URL so you can test in OBS first.

Good to know

The control panel must stay open while collecting entries. The OBS overlay only displays the room state.

Twitch chat is read anonymously. Kick chat is read through the RustyBot service. Announcements are posted as the_rusty_bot.

Rooms expire after 12 hours of inactivity. No EVE login is required.

FAQ

Is Rustybot Source free?
Yes. Create a room, run the draw and use the OBS overlay for free. There are no viewer accounts and no paid tiers.
Do viewers need a Twitch or Kick account?
They just need to be able to type in your chat. Type the entry command (default !join) and they're in. No sign-in, no form.
Does it work with both Twitch and Kick at the same time?
Yes. Set both channels on the room and entries from either chat go into the same draw. Duplicate names are ignored.
What is EVE mode?
After a winner confirms, Rustybot Source looks up the name through EVE ESI and shows the character portrait, corporation and alliance on the overlay. Normal mode just shows the username.
How does winner confirmation work?
The winner has 90 seconds to type anything in chat. If they don't, they're removed from the entry pool and you can start another draw. You can also confirm manually from the control panel.
Can I show a countdown on the overlay?
Yes. In the control panel, set the timer seconds and click Start Timer. The overlay shows a "Giveaway ends in" countdown; End Timer stops it.
Do alerts need a bot account?
No. The alert overlay uses Twitch EventSub and Kick's event webhooks, authorised by your own channel. The RustyBot chat account is only used for giveaway announcements.
Does the alert control panel need to stay open?
No. Once the overlay is created and the channels are connected, alerts run on the Rustybot Source server. OBS only needs the alert overlay URL.
How long does a room last?
Giveaway-only rooms expire after 12 hours of inactivity. Rooms with alerts enabled stay live until you delete them. You can delete a room from its control panel at any time.
Can I use my own bot account?
Rustybot Source uses the RustyBot shared bot for Twitch and Kick announcements. Chat entries are read without logging in as the bot. If you need a dedicated bot setup, contact us on Discord.
